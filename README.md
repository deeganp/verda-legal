# Verda — Legal

Public hosting for Verda's legal documents, served via GitHub Pages.

| Document | URL |
|---|---|
| Privacy Policy | https://deeganp.github.io/verda-legal/privacy/ |
| Terms & Conditions | https://deeganp.github.io/verda-legal/terms/ |
| Content Guidelines | https://deeganp.github.io/verda-legal/guidelines/ |

## Updating

These pages are generated from `Legal/*.html` in the
[Verda_react_native](https://github.com/deeganp/Verda_react_native) repo, which
is also what the app renders in-app. When those change, regenerate and push here
so the public copies stay in sync.

The privacy policy URL is referenced by:
- Google Play Console → Policy → App content → Privacy policy
- Google Cloud → OAuth consent screen (required for Google Sign-In)
- App Store Connect
